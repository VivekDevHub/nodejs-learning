# Product CRUD API Task

# Product Management CRUD API Task

## Objective

You have to build a **Product Management CRUD API** where you can perform:

* Create Product
* Read Product
* Update Product
* Delete Product

This is called **CRUD Operations**.

---

# Resource Name

## products

---

# Product Fields

Each product should have the following fields:

* **name** (String)
* **price** (Number)
* **description** (String)
* **category** (String)
* **stock** (Number)
* **createdAt** (Date)

---

# API Endpoints Required

You need to create the following API endpoints:

## 1. Create Product

Add a new product to the system.

### Method:

`POST`

### Route:

`/api/products`

---

## 2. Get All Products

Fetch all available products.

### Method:

`GET`

### Route:

`/api/products`

---

## 3. Get Single Product by ID

Fetch one specific product using product ID.

### Method:

`GET`

### Route:

`/api/products/:id`

---

## 4. Update Product by ID

Update an existing product using product ID.

### Method:

`PUT`

### Route:

`/api/products/:id`

---

## 5. Delete Product by ID

Delete a product using product ID.

### Method:

`DELETE`

### Route:

`/api/products/:id`
